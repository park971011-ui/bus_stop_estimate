# 평일 혼합 비율 실험 보고서

## 1. 목적과 기준

두 비율 선택을 기존 E56 기반 평일 혼합 모델의 저장된 날짜별 검증 예측으로 비교했다. 비교 점수는 월·화·수(2024-09-23~2024-09-25) 각각의 **검증 MAE(초)**다. 이는 날짜를 통째로 제외한 교차검증 결과이며 **대회 Public MAE가 아니다.** 날짜별 검증 행 수는 각각 40,085, 40,223, 40,461행이다(합계 120,769행).

기준 구성은 다음과 같다.

- 외부 혼합: 전체 날짜 학습 모델 조합 50% + 평일 전용 LightGBM 50%
- 전체 날짜 조합 내부: LightGBM 80% + CatBoost 20%

보고서의 Δ는 각 후보 점수에서 해당 실험의 기준 점수를 뺀 값이다. MAE·RMSE의 Δ는 **반올림 전 값으로 계산한 다음** 표시에 맞춰 반올림했다. 양수는 기준보다 오차가 커졌음을, 음수는 작아졌음을 뜻한다. MAE가 날짜별 주 평가 점수이며, 120,769행 통합 지표는 보조 요약이다.

## 2. 실험 1 — 전체 날짜 조합 : 평일 전용 모델

### 변경한 것과 고정한 것

- **변경**: 외부 가중치 `전체 날짜 조합 : 평일 전용 LightGBM`을 30:70, 50:50, 70:30으로 비교했다.
- **고정**: 전체 날짜 조합 내부의 `LightGBM : CatBoost`는 80:20. 각 구성 요소의 학습 예측, 피처·전처리 및 날짜별 검증 분할도 고정했다.
- **예측 근거**: `oof_blend_predictions.parquet`의 `pred_all`(내부 80:20 조합)과 `pred_wd_lgb`를 선형 결합하고 저장된 정답과 비교했다. 저장된 검증 예측으로 세 비율 후보를 계산했다.

### 날짜별 검증 MAE

| 전체 날짜 조합 : 평일 전용 | 월 MAE | Δ vs 50:50 | 화 MAE | Δ vs 50:50 | 수 MAE | Δ vs 50:50 |
|---|---:|---:|---:|---:|---:|---:|
| **30:70** | 23.511 | +0.012 | 23.196 | -0.020 | 22.996 | +0.005 |
| **50:50 기준** | 23.499 | 0.000 | 23.217 | 0.000 | 22.991 | 0.000 |
| **70:30** | 23.503 | +0.004 | 23.255 | +0.038 | 23.005 | +0.014 |

### 보조 통합 지표

| 비율 | 120,769행 Pooled MAE | Pooled MAE Δ vs 50:50 | Pooled RMSE |
|---|---:|---:|---:|
| 30:70 | 23.234 | -0.001 | 41.056 |
| 50:50 기준 | 23.235 | 0.000 | 40.995 |
| 70:30 | 23.253 | +0.019 | 40.981 |

30:70은 전체 통합 MAE에서 약 0.001초 낮았지만 날짜별 MAE는 화요일만 개선됐고, RMSE는 약 0.062초 높았다. 70:30은 MAE가 세 날짜 모두 높았으나 통합 RMSE는 약 0.013초 낮았다. 지표와 날짜에 따라 결과가 달라져 30:70의 작은 통합 MAE 차이만으로 기존 외부 비율을 바꾸지 않았다.

## 3. 실험 2 — 전체 날짜 조합 내부의 LightGBM : CatBoost

### 변경한 것과 고정한 것

- **변경**: 전체 날짜 조합 내부 `LightGBM : CatBoost` 가중치를 100:0, 90:10, 80:20, 70:30으로 비교했다.
- **고정**: 외부 조합은 `전체 날짜 조합 : 평일 전용 LightGBM = 50:50`. 세 모델의 저장된 개별 날짜별 예측, 전처리 및 검증 분할도 고정했다.
- **예측 근거**: 각 검증 날짜에 대해 `all_lgb`, `all_cb`, `wd_lgb` 체크포인트 예측 9개를 `row_id`로 정답 행에 정렬한 다음 결합했다. 세 날짜 모두 누락·불일치 행이 없었다. 저장된 검증 예측으로 네 비율 후보를 계산했다.

### 날짜별 검증 MAE

괄호 안 Δ는 동일 날짜의 기존 내부 비율 80:20 대비 후보 MAE 변화다.

| 내부 LGB:CB | 월 MAE (Δ) | 화 MAE (Δ) | 수 MAE (Δ) |
|---|---:|---:|---:|
| **100:0** | 23.512 (+0.012) | 23.210 (-0.007) | 22.984 (-0.007) |
| **90:10** | 23.504 (+0.005) | 23.212 (-0.005) | 22.986 (-0.005) |
| **80:20 기준** | 23.499 (0.000) | 23.217 (0.000) | 22.991 (0.000) |
| **70:30** | 23.497 (-0.003) | 23.225 (+0.008) | 22.998 (+0.007) |

### 보조 통합 지표

| 내부 LGB:CB | 120,769행 Pooled MAE | MAE Δ vs 80:20 | Pooled RMSE | RMSE Δ vs 80:20 |
|---|---:|---:|---:|---:|
| 100:0 | 23.234 | -0.001 | 41.100 | +0.106 |
| 90:10 | 23.233 | -0.002 | 41.044 | +0.050 |
| 80:20 기준 | 23.235 | 0.000 | 40.995 | 0.000 |
| 70:30 | 23.239 | +0.004 | 40.952 | -0.043 |

90:10은 시험한 네 비율 중 통합 MAE가 가장 낮았지만 80:20과 차이는 약 0.00168초(약 1.7밀리초)였다. 월요일 MAE는 오히려 약 0.005초 높았고 RMSE도 약 0.050초 높았다. 100:0의 통합 MAE 차이도 약 0.00058초(약 0.6밀리초)로 작았으며 날짜별 결과가 갈렸다. 70:30은 월요일 MAE가 조금 낮았지만 화·수요일과 통합 MAE는 높았고, 통합 RMSE는 더 낮았다.

## 4. 결론

두 실험 모두 작은 통합 MAE 차이와 날짜별로 엇갈리는 결과를 보였다. 외부 비율 30:70의 약 1.1밀리초 통합 MAE 이득은 월·수요일 악화 및 RMSE 증가와 함께 나타났다. 내부 90:10의 약 1.7밀리초 이득도 월요일 악화 및 RMSE 증가를 동반했다. 반대로 RMSE가 낮은 후보가 모든 날짜 MAE에서 우세하지는 않았다.

따라서 관측된 결과만으로 비율 변경의 안정적인 이득을 확인하기 어렵고, **기존 외부 50:50 및 내부 80:20 설정을 유지했다.** 이 결론은 세 날짜 검증과 비교한 비율에 한정되며, 최적 비율을 입증하거나 다른 데이터 기간·Public 점수를 보장하지 않는다.

## 5. 기존 코드 활용과 이번 비교·분석

- **기존 코드 활용**: `run_weekday_blend.py`의 E56 기반 전처리·피처 구성, 세 구성 요소 모델, 월·화·수 날짜별 검증, 저장 예측 및 외부 30:70·50:50·70:30 집계를 활용했다. 저장 기준은 기존 E56 기반 평일 혼합 50:50이다.
- **저장 예측 재사용**: 외부 비율은 저장 OOF 예측에서 다시 계산했다. 내부 비율은 저장된 세 모델 체크포인트와 검증 정답을 사용해 `eval_inner_ratios.py`의 집계 로직으로 계산한다. 이 스크립트는 예측을 결합해 지표를 산출한다.
- **비율 비교·해석**: 두 비율 축의 정의와 고정 조건을 분리해 명시하고, 반올림 전 차이로 날짜별 MAE와 보조 통합 지표를 비교해 기존 비율 유지 결론을 정리했다. 

## 6. 입력 파일 및 실행 방법

- **외부 비율 재계산**: `oof_blend_predictions.parquet` (정답, `pred_all`, `pred_wd_lgb` 포함)
- **내부 비율 재계산**: `data/final/train.parquet`와 `checkpoints/all_lgb_2024-09-23.npz` 등 세 모델×세 날짜의 9개 예측 체크포인트
- **학습·OOF 생성 스크립트**: `run_weekday_blend.py` — 입력은 `data/final/train.parquet`, `data/final/test.parquet`; 체크포인트가 없거나 행 ID가 불일치하면 학습할 수 있다. 프로젝트 루트에서 `python dayun/weekday_blend_experiment/run_weekday_blend.py`로 실행한다.
- **내부 비율 집계 스크립트**: `eval_inner_ratios.py` — 모델 학습 없이 저장 체크포인트와 `train.parquet`을 읽고 `inner_ratio_summary.csv`를 생성한다. 프로젝트 루트에서 `python dayun/weekday_blend_experiment/eval_inner_ratios.py`로 실행한다. 두 스크립트의 `BASE_DIR`은 작성 환경의 저장소 위치를 가리키므로, 다른 clone에서는 저장소 루트에 맞춰 조정한다.
- Python 패키지: 저장소 루트 `requirements.txt` 참조 (핵심: NumPy, Pandas, PyArrow, LightGBM, CatBoost).
