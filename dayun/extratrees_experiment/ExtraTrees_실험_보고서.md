# ExtraTrees 실험 보고서

## 1. 목적과 기준 모델

실험 목적은 E56 기반 평일 혼합 예측에 평일 전용 ExtraTrees 예측을 단독 적용하거나 일부 섞었을 때의 성능 변화를 확인하는 것입니다. 기준 모델은 다음 혼합입니다.

- 외부 혼합: 전체 날짜 조합 : 평일 전용 모델 = **50:50**
- 내부 전체 날짜 조합: LightGBM : CatBoost = **80:20**
- 기준 예측: `pred_base = 0.5 × (0.8 × all_lgb + 0.2 × all_cb) + 0.5 × wd_lgb`

비교 대상은 **기준 / ExtraTrees 단독 / 기준 90%+ExtraTrees 10% / 기준 80%+ExtraTrees 20%**입니다. Δ는 후보 MAE에서 기준 MAE를 뺀 값이며 양수는 악화, 음수는 개선입니다. MAE와 RMSE 차이는 저장 예측의 반올림 전 값으로 계산한 뒤 소수 셋째 자리까지 표시했습니다.

점수는 Phase 1의 월·화·수 OOF 검증 결과와 Phase 2의 연습용 목·금 데이터 평가 결과입니다. 모두 내부 검증 점수이며 **대회 Public MAE가 아닙니다.**

## 2. Phase 1 — 평일 OOF 검증

### 조건 및 피처 차이

- 데이터: `data/final/train.parquet` 154,327행. 2024-09-23(월), 09-24(화), 09-25(수)를 날짜별로 하나씩 제외하고 나머지 평일로 학습했습니다. 검증행은 각각 40,085, 40,223, 40,461행(합계 120,769행)입니다.
- 기준: 36개 입력 피처(기본·운행 25개, 회차 힌트 `H` 10개, `turn_est` 1개).
- ExtraTrees: 35개 입력 피처. `turn_est`를 제외하고 `H` 10개는 유지했습니다. **이번 구현에서 `H` 피처의 NaN을 0으로 대체해 입력했습니다.** 범주형 열은 `cat.codes` 정수 코드로 변환했습니다.
- ExtraTrees 설정: `n_estimators=500`, `min_samples_leaf=10`, `max_features=0.6`, `random_state=0`, `n_jobs=-1`.
- 혼합 예측: 기준 90%+ET 10%, 기준 80%+ET 20%는 같은 기준·ET 저장 예측의 선형결합입니다. 각 혼합마다 별도 모델을 학습한 것은 아닙니다.

기준과 ExtraTrees는 피처 수·피처 내용·결측 처리·범주형 인코딩 방식에 차이가 있습니다. 따라서 결과 차이를 모델 종류만의 효과로 분리해서 해석할 수 없습니다. 특히 기준은 `turn_est`를 포함하지만 ExtraTrees에는 없고, ExtraTrees의 `H` 결측값은 이번 구현에서 0으로 대체했습니다.

### 전체 및 날짜별 결과

아래 수치는 초 단위입니다. 날짜별 검증 MAE가 주 결과이고, 통합 MAE/RMSE는 120,769개 검증행을 합친 보조 요약입니다.

| 모델 / 혼합 | 월 MAE | 화 MAE | 수 MAE | Pooled MAE | MAE Δ vs 기준 | Pooled RMSE | RMSE Δ vs 기준 |
|---|---:|---:|---:|---:|---:|---:|---:|
| **기준 E56 혼합** | 23.499 | 23.217 | 22.991 | 23.235 | 0.000 | 40.995 | 0.000 |
| ExtraTrees 단독 | 25.059 | 24.786 | 24.558 | 24.800 | +1.565 | 40.967 | -0.028 |
| **기준 90% + ET 10%** | 23.535 | 23.259 | 23.010 | 23.267 | **+0.032** | 40.721 | **-0.274** |
| 기준 80% + ET 20% | 23.607 | 23.337 | 23.071 | 23.337 | **+0.102** | 40.506 | **-0.488** |

| 날짜 | 검증행 | ET 단독 MAE | 기준 90%+ET 10% MAE (Δ) | 기준 80%+ET 20% MAE (Δ) |
|---|---:|---:|---:|---:|
| 월 2024-09-23 | 40,085 | 25.059 | 23.535 (+0.035) | 23.607 (+0.107) |
| 화 2024-09-24 | 40,223 | 24.786 | 23.259 (+0.043) | 23.337 (+0.120) |
| 수 2024-09-25 | 40,461 | 24.558 | 23.010 (+0.019) | 23.071 (+0.080) |

각 날짜에서 두 혼합의 MAE가 모두 기준보다 높았습니다. 통합 RMSE는 10% 혼합에서 0.274초, 20% 혼합에서 0.488초 낮게 관측됐습니다. 이 결과는 관측된 지표 변화이며 특정 모델 구조가 RMSE 감소를 일으켰다고 확정하지 않습니다.

## 3. Phase 2 — 연습용 목·금 별도 추가 실험

Phase 2는 Phase 1 설정을 그대로 재검증한 단계가 아닙니다. `data/practice`의 연습용 학습·평가 자료를 사용한 별도 추가 실험입니다. 이 연습 자료는 이전의 `experiments/sunday_weight_experiment/`와 `dayun/conditional_blend_practice/`에서도 사용됐습니다.

- 평가 데이터: 2024-09-26(목) 28,853행, 2024-09-27(금) 28,713행(합계 57,566행).
- Phase 1과 달리 기준과 ExtraTrees 모두 `prep()` 없이 기본·운행 **25개 피처**를 사용했습니다. 두 모델 간 비교에 피처 수 차이는 없지만, Phase 1과 피처 구성이 달라 Phase 1 결과를 그대로 재검증한 것으로 볼 수 없습니다.
- Phase 1에서 비교한 비율 중 기준 90%+ET 10%를 Phase 2에 적용했습니다. Phase 2에서 다른 혼합 비율을 추가 탐색하지 않았습니다.

| 모델 / 혼합 | 목 MAE | 금 MAE | Pooled MAE | MAE Δ vs Phase 2 기준 | Pooled RMSE | RMSE Δ vs 기준 |
|---|---:|---:|---:|---:|---:|---:|
| **기준 25피처 혼합** | 25.580 | 26.957 | 26.267 | 0.000 | 50.779 | 0.000 |
| ExtraTrees 단독 | 27.301 | 28.385 | 27.842 | +1.575 | 49.888 | -0.891 |
| **기준 90% + ET 10% (고정)** | 25.632 | 26.987 | 26.308 | **+0.041** | 50.502 | **-0.277** |

Phase 2의 10% 혼합 MAE는 목요일 약 0.051초, 금요일 약 0.030초 높았습니다. Pooled RMSE는 0.277초 낮았습니다. 이는 다른 연습 데이터와 25피처 설정에서 관측된 별도 결과입니다.

## 4. 해석과 결론

두 단계 모두 비교한 혼합의 MAE가 기준보다 높아 이번 설정에서는 ExtraTrees 혼합을 채택하지 않았습니다. Phase 1 10%·20% 혼합의 통합 MAE는 각각 0.032초·0.102초 악화했고, 월·화·수 모두 MAE가 높았습니다. Phase 2 10% 혼합은 통합 MAE가 0.041초 악화했고 목·금 모두 높았습니다.

RMSE는 Phase 1 10%·20% 혼합과 Phase 2 10% 혼합에서 각각 0.274초·0.488초·0.277초 낮게 관측됐습니다. MAE와 RMSE가 서로 다른 방향을 보였으나, 원인을 모델 구조 하나로 단정하지 않습니다.

## 5. 한계

1. **Phase 1 비교의 동시 변경 요인**: 기준은 36개, ExtraTrees는 35개 피처를 사용하고 `turn_est`, 결측값 처리, 범주형 표현도 다릅니다. 효과를 ExtraTrees 모델 종류 하나에 귀속할 수 없습니다.
2. **범주 목록 구성**: 두 실행 스크립트는 `route_id`, `seg_id` 범주와 `last_seq`를 학습·검증·평가 입력 메타데이터 전체에서 구성합니다. 학습 폴드 안에서만 범주 목록을 만든 대안으로는 점수를 다시 계산하지 않았습니다.
3. **Phase 2 독립성**: Phase 2 연습 자료는 이전 실험에서도 사용됐습니다. Phase 2는 별도의 25피처 확인이며 새로운 독립 데이터셋 결과나 Phase 1 설정의 재검증으로 해석하지 않습니다.
4. **평가 범위**: 결과는 지정된 내부 날짜 검증 및 연습 목·금 평가에 한정됩니다. 대회 Public MAE나 다른 날짜의 성능을 나타내지 않습니다.
5. **결측값 설명 범위**: `NaN`을 0으로 바꾼 것은 본 ExtraTrees 구현의 입력 처리입니다. 이를 모든 ExtraTrees 버전에 대한 일반 규칙으로 확대하지 않습니다.

## 6. 파일 및 실행 방법

저장소 루트 기준 필요한 입력:

- Phase 1: `data/final/train.parquet`, `data/final/test.parquet`, 그리고 `dayun/weekday_blend_experiment/checkpoints/`의 `all_lgb`, `all_cb`, `wd_lgb` 날짜별 기준 예측 9개.
- Phase 2: `data/practice/train.parquet`, `data/practice/test.parquet`.
- 환경: 저장소 루트 `requirements.txt`의 Python 의존성.

저장소 루트에서 Phase 1은 `python dayun/extratrees_experiment/run_et_weekday.py`, Phase 2는 `python dayun/extratrees_experiment/run_et_practice.py`로 실행합니다. 실행 스크립트는 ET 체크포인트가 없거나 검증 행 ID와 맞지 않을 때 학습을 수행할 수 있습니다. 노트북은 `jupyter notebook dayun/extratrees_experiment/extratrees_experiment.ipynb`로 열 수 있으며, 상단의 재학습 플래그가 `False`이면 저장 체크포인트를 읽고, `True`이면 해당 모델을 학습합니다.
