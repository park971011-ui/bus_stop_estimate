## 3. E78 정각 넘김 피처 (길이 편향)

### 가설
- 데이터에는 분이 없고 `arrive_hour`(시)만 있음
- 구간이 길수록 그 사이에 정각을 지날 확률이 높음 (확률 ≈ 통행시간 / 3600)
- 그러니 **바로 다음 행의 시가 바뀌었다 = 이 구간이 평소보다 길었을 가능성이 큼**. 정답 없이 입력만으로 알 수 있음

### 확인
- 정각 넘긴 행(3%): 실제 중앙값 136초인데 E41 예측 중앙값 120초 → 모델이 짧게 예측, 잔차 평균 +19.8초 (안 넘긴 행 +2.5초)

### 피처
- `h_cross` = 같은 운행 바로 다음 행(stop_seq + 1)의 시 − 이 행의 시
- `h_cross_prev` = 이 행의 시 − 바로 앞 행의 시

### 검증 (채택 기준 미리 고정: 두 검증 모두 개선, 대회는 평일 2/3일 이상)

| | 대회 4-fold 예상 | 정각 넘긴 행 | 연습 진짜 목·금 |
|---|---|---|---|
| E41 피처 | 25.227 | 42.19 | 26.102 |
| E41 + 정각 넘김 | 25.199 | 41.14 | 26.042 |
| E74 조합 | 25.113 | 42.21 | 26.142 |
| **E74 조합 + 정각 넘김** | **25.080** (평일 3/3) | **41.01** | **26.076** |

→ E74 조합 + 정각 넘김이 **두 검증 모두 기준(E41)보다 좋음 → 채택**

## 4. E79 제출 구성

```
목·금 = 0.5 × (기본 LGB 0.8 + CatBoost 0.2, 월·화·수·토 학습)
      + 0.5 × 평일 전용 LGB (월·화·수만)
      피처 45개 = E41 35개 + peak2 + wkhour + turn + turn_est + h_cross, h_cross_prev
일요일 = E73 (일요일 모델 + 같은 날 연습 기록)
```

## 5. 발표에서 말할 것

### 1) 정각 넘김 = 데이터의 "빈틈"을 정보로 바꿈
- 분 단위 시각이 없어서 불리한 데이터인데, 오히려 "시가 바뀐 지점"이 통행시간 단서가 됨
- 이 생각을 끝까지 밀어붙인 게 E87·E89 LP 분 복원 (`E89_LP_분복원_회차역산_설명.md`)

### 2) 날짜를 외우는 피처는 독 (E74 blk·rhour, E83)
- E83에서 길이 편향을 더 넓힘(운행 전체 정각 넘김 수, 주변 구간 정각 넘김, 그날 차량 수 등)

| E83 | 대회 4-fold | 연습 목·금 | 연습 일요일(참고) |
|---|---|---|---|
| 기준 (E79 45개) | 25.080 | 26.076 | 29.979 |
| 전부 추가 | 25.412 | 26.499 | **29.239** |

- 평일은 3일 다 나빠지고 **토·일만 좋아짐**
- 교훈: **날마다 값이 달라지는 피처는 처음 보는 요일(토·일)에는 도움, 학습에 있던 요일(평일)에는 날짜 외우기로 손해** (E73 같은 날 연습 기록과 같은 패턴)

### 3) 검증이 엇갈릴 때
- E74는 대회 검증 개선·연습 검증 악화 → 정각 넘김을 더한 뒤 **두 검증 모두 통과**하는 조합을 찾고 나서 제출
- 실제로 public −0.132로 확인됨

### 4) 다른 모델 섞기는 효과 없었음 (E77)
- RandomForest·ExtraTrees 단독 26.73~26.77 (LGB+CB 섞기 25.229보다 1.5 나쁨), 0.1~0.3 섞어도 4일 다 나빠짐
