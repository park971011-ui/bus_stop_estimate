# E73 일요일 모델 + 같은 날 연습 기록 피처

- 스크립트: `scripts/E73_sunday_px.py` (`cv` → 검증, `make` → 제출 파일)
- 제출 파일: `submissions/final_E73_sunday_px.csv` (단독 public 기록 없음)
- **E79(24.117)·E89 MD(24.098, 우리 최고)의 일요일 부분이 이 모델임**

---

## 1. 한 줄 요약

> 연습 데이터는 대회 데이터와 **날짜가 같음**(2024-09-23~29). 그래서 "그날 그 시간에 대전 도로가 평소보다 얼마나 막혔나"를 연습 노선 기록에서 읽어 와 일요일 모델에 넣었더니, 일요일 MAE 27.762 → **27.340 (−0.422)**.

---

## 2. 아이디어

- 대회 train에는 일요일이 없음 → 일요일은 처음 보는 요일
- 연습 test에는 **진짜 일요일(09-29) 정답**이 있음. 노선은 다르지만 같은 날 같은 도시
- 같은 도로를 같은 시간에 달렸다면, 연습 노선이 평소보다 느렸던 시간대엔 대회 노선도 느렸을 것
- 처음 시도(E69)에서 **처음 보는 요일(토요일 fold)만** 좋아짐(30.126 → 29.641), 평일은 나빠짐 → 일요일 모델에만 넣기로 함
- 연습 데이터 사용은 교수님께 허용 확인받음 (EVALUATION.md "수업에서 제공한 데이터만 씀")

---

## 3. 피처 6개 (`px_*`)

| 피처 | 뜻 |
|---|---|
| `px_seg_hr` | 같은 구간(정류장 쌍)·같은 날·같은 시의 연습 통행시간 중앙값 (구간이 겹칠 때만) |
| `px_seg_r` | 같은 구간의 그날 그 시 log(실제 / 평소) 평균 = 평소 대비 얼마나 느렸나 |
| `px_seg_n` | 그 기록 수 |
| `px_near_r` | **반경 500m 안, 같은 방향**(방향 벡터 내적 > 0.7) 연습 구간들의 그날 그 시 평소 대비 비율 |
| `px_near_n` | 근처 구간 기록 수 |
| `px_glob_r` | 연습 데이터 전체의 그날 그 시 평소 대비 비율 중앙값 (도시 전체 혼잡도) |

**누출 방지:** 연습 노선 행은 **자기 노선을 뺀** 연습 데이터로만 계산. 검증 때 빠진 노선의 연습 test는 피처 계산에도 안 씀.

## 4. 검증 (실습 노선 하나 빼고 그 노선 일요일 맞히기, 4번)

채택 기준(미리 고정): 기준보다 낮고, 4개 노선 중 3개 이상 좋아지면 채택.

| 일요일 MAE | 전체 | 1번 | 102번 | 511번 | 605번 |
|---|---|---|---|---|---|
| 기준 (E58 일요일 모델, LightGBM) | 27.762 | | | | |
| **+ 같은 날 연습 기록** | **27.340** | −0.69 | +0.12 | −0.43 | −1.27 |

→ 3/4 노선 개선, **채택**. 제출 파일은 E67 방식(LGB 0.8 + CB 0.2, 일·토 배차 다른 노선만 일요일 ×2)으로 만듦.
대회 일요일 예측은 E67 대비 평균 −0.06초, 평균 |차이| 5.02초 (B1 +5.1초).

## 5. 발표에서 말할 것

### 1) "처음 보는 날"에는 그날의 외부 정보가 결정적
- 평일(학습에 있던 요일): 같은 날 연습 기록을 넣으면 **나빠짐** (E69, 23.322 → 23.377~23.611) → 모델이 날짜를 외움
- 토·일(처음 보는 요일): **좋아짐** → 학습 데이터로 알 수 없는 "그날 상황"을 채워 줌
- 같은 패턴이 E83에서도 반복됨 (날마다 달라지는 피처 = 처음 보는 요일엔 도움, 본 요일엔 손해)

### 2) 일요일에 더 넣어 봤지만 다 실패한 것 → 연습 기록이 이미 다 담고 있음

| 실험 | 일요일에 추가 | 결과 | 노선 개선 |
|---|---|---|---|
| E80 | 정각 넘김 (목·금에선 효과 있었음) | 27.340 → 27.405 | 1/4 |
| E84 | 운행 길이 편향·운행 규모 | 27.392 / 27.387 / 27.521 | 1/4, 1/4, 0/4 |
| E88 | LP 분 복원 (목·금에선 효과 있었음) | 27.349 / 27.356 | 2/4 |

- 해석: 정각 넘김·분 복원은 "이 행이 평소보다 오래 걸렸다"는 간접 증거인데, 연습 기록 피처가 **그날 그 시 도로 상황을 직접** 주니까 겹침

### 3) 근처 도로를 쓰는 방법
- 연습 노선과 대회 노선은 겹치는 구간이 적음(같은 구간 피처 있는 행 약 7%) → 반경 500m·같은 방향 구간으로 넓혀서 약 25% 행에 정보를 줌
