# 2026-11-21 대회 당일 체크리스트

## 꼭 기억할 규칙 (README, EVALUATION.md)

- **대회 노선 5개는 연습 노선(1·102·511·605번)과 겹치지 않음.** → 노선별 분석(1번 seq21 등)은 그대로 못 씀. 방법(검증 틀, 피처 만드는 코드, 모델 설정)만 가져감.
- 제출: **하루 3회** (한국 시간 0시 초기화), 형식 오류는 횟수에 안 셈. 사이트 https://am.dtumos.com/
- 채점: test를 **퍼블릭 30% / 프라이빗 70%**로 나눔. 리더보드(퍼블릭)는 일부일 뿐 → **퍼블릭 점수에 맞춰 고르지 말고 검증 점수로 고르기.**
- **최종 제출 1개를 직접 골라야 함.** 안 고르면 퍼블릭 최고가 자동 선택됨.
- 개선 점수: 프라이빗 MAE가 "노선·방향·정류장·시간대 평균"(E0)보다 낮아야 받음 → 검증에서 E0과 비교.
- 재현성: 제출 노트북이 처음부터 끝까지 돌아가야 함 (`RUN_EXPERIMENTS = False`로).
