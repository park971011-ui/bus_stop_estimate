# 데이터 README (대전 BIS 버스 구간 통행시간)

## 1. 무엇을 예측하나

버스 한 대가 **정류장 A에 도착한 순간부터 다음 정류장 B에 도착할 때까지** 걸린 시간 `tt_sec`(초)를 예측함.
A에서 정차한 시간도 포함됨.

| 항목 | 내용 |
|---|---|
| 출처 | 대전광역시 BIS 버스 운행 기록 |
| 기간 | 2024-09-23(월) ~ 2024-09-29(일), 7일 |
| 한 행 | 버스 한 대가 정류장 A → 바로 다음 정류장 B로 간 기록 하나 |
| 노선 | 5개 (실습용·대회용 각각) |
| 채점 | MAE (낮을수록 좋음) |

## 3. 컬럼

| 컬럼 | 뜻 |
|---|---|
| `row_id` | 행 ID |
| `route_id`, `route_nm` | 노선 ID, 노선 번호 |
| `route_type` | 노선 유형: 1 급행, 2 간선, 3 지선, 4 외곽, 5 마을, 6 첨단, 7 광역 |
| `vehicle_id` | 차량 ID |
| `direction` | 상하행: 0 상행, 1 하행 |
| `interval_wd` / `interval_sat` / `interval_sun` | 배차간격(분): 평일, 토요일, 일요일 |
| `first_time`, `last_time` | 평일 기점 첫차·막차 출발 시각 (HHMM, 545 = 05:45) |
| `from_stop`, `from_name`, `from_lat`, `from_lon` | 출발 정류장 ID, 이름, 위도, 경도 |
| `to_stop`, `to_name`, `to_lat`, `to_lon` | 도착 정류장 ID, 이름, 위도, 경도 |
| `stop_seq` | 출발 정류장이 노선(그 방향)에서 몇 번째인지 |
| `dist_m` | 두 정류장 사이 거리(m) |
| `date` | **출발 정류장에 도착한** 날짜 (YYYY-MM-DD) |
| `arrive_hour` | **출발 정류장에 도착한** 시 (0~23) |
| **`tt_sec`** (예측 대상) | 출발 정류장 도착 → 도착 정류장 도착까지 걸린 시간(초). 출발 정류장 정차시간 포함 |

### 헷갈리기 쉬운 점

- `date`, `arrive_hour`는 **출발 정류장(A) 기준**. 도착 정류장(B) 시각이 아님.
- `first_time`, `last_time`은 **평일 기준**. 주말 첫차·막차는 따로 없음.
- `tt_sec`에 **A에서 서 있던 시간이 포함**됨. 그래서 종점·회차 구간은 거리가 짧아도 시간이 길 수 있음.
- test에는 `tt_sec`이 없음 (실습 test만 정답이 있음).
