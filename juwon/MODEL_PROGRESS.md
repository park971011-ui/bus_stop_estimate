## 2. 데이터 진단 및 실험을 통해 검증된 핵심 인사이트

1. **평일(dow 3, 4) vs 일요일(dow 6) 분리 전략의 유효성**
   * E79(24.117) 대비 E89(24.0) 비교 결과, 일요일(dow == 6) 예측값은 0.0000 차이로 동일하며 E73sun 모델이 이미 최적화되어 있음.
   * 점수 하락(-0.117)은 평일(dow 3, 4) 구간의 꼬리 오차 제어(최댓값 1709.4초 -> 1618.3초)와 L1/Lp 손실 기반 미세 보정(평균 -0.15~-0.17초, 절대값 평균 2.25~2.29초)에서 발생함.
2. **임의 상수 후처리의 한계 및 OOF 검증 원칙**
   * 검증 없이 경험적 상수를 곱해 평균을 강제 하향(108.67초 -> 107.68초)했을 때 정상 구간 오차가 증가함.
   * 날짜 단위 6-Fold GroupKFold OOF MAE가 개선된 모델만 고점수 베이스(E89) 대비 좁은 클리핑([-2.2, +2.2]초)과 보수적 가중치(15%)로 결합하는 원칙을 확립함.
3. **23점대 돌파를 위한 핵심 피처 엔지니어링**
   * **동일 차량 연속 주행 시퀀스(Trip Sequence):** (date, vehicle_id) 기준 trip_idx를 분리하여 누적 이동 거리(cum_dist), 운행 순번(trip_order), 직전/직후 구간 거리 비율(dist_r_prev/next), 교차로 회전각(turn_prev/next) 산출.
   * **당일 실시간 노선·시간대 운행 밀도(Corridor Density):** (date, route_id, direction, arrive_hour) 기준 차량당 정류장 주파 수(spv)로 당일 도로 혼잡도 반영.

## 3. 프로젝트 주요 스크립트 및 파일 구조

* **src/break_23_mid.py**: 날짜 단위 6-Fold GroupKFold 기반 2-Stage 잔차 스태킹(LightGBM L1 + CatBoost MAE) 및 final_23mid_safe.csv / final_23mid_push.csv 생성 스크립트.
* **src/force_23mid.py**: 고점수 3종 중앙값 앙상블 및 비대칭 편향 보정 실험 스크립트.
* **notebooks/my_model.ipynb**: E89 vs E79 요일·노선별 차이 진단 및 E89(24.0) 기반 평일 시퀀스·밀도 OOF 보정 파이프라인(submissions/final_E89_seq_calibrated.csv 생성).

## 4. 향후 액션 플랜 (23점대 중반 돌파 로드맵)

1. **submissions/final_E89_seq_calibrated.csv 제출 및 검증:** E89(24.0) 대비 평일만 안전하게 보정한 모델로 23점대 진입 여부 확인.
2. **평일 전용 lpMD 구조에 시퀀스·밀도 피처 직접 통합:** 후처리 블렌딩을 넘어, E89의 핵심인 평일 lpMD 학습 파이프라인 자체에 cum_dist, turn_prev/next, spv 피처를 직접 투입하여 단일 모델 OOF MAE 단축.
3. **고정체·장거리 구간(상위 5%) 타겟 손실 함수 튜닝:** 평일 출퇴근 첨두시간(07~09시, 17~19시) 및 장거리 구간의 과대예측 꼬리를 억제하기 위한 구간별 가중 L1/Huber 앙상블 고도화.
