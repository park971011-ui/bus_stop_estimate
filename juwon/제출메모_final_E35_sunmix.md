# 제출 메모: final_E35_sunmix.csv

| 항목 | 내용 |
|---|---|
| 파일 | `bis-travel-time-practice/submissions/final_E35_sunmix.csv` (111,563행, 결측 0) |
| 모델·피처 | **E32와 같음** (LightGBM × 0.8 + CatBoost × 0.2, E5 피처 25개). 다시 학습하지 않고 예측만 바꿈 |
| 바뀐 것 | **일요일 행만**: "토요일처럼" 예측과 "평일처럼" 예측을 반반 섞음 |
| 바뀐 행 | 30,509행 (일요일 30,848행 중. 나머지 339행은 반올림하면 값이 같음). 목·금 행은 0행 바뀜 |

## 방법

일요일 행을 두 번 예측해서 평균 냄. 요일 정보가 들어 있는 피처 두 개만 바꿈.

| | `is_weekend` | `interval` (배차 간격) |
|---|---|---|
| 토요일처럼 | 1 | 토요일 배차 |
| 평일처럼 | 0 | 평일 배차 |
| 최종 | 위 두 예측 × 0.5씩 | |

## 근거: 연습 데이터 모의고사 (대회와 같은 구조: 월·화·수·토 학습 → 목·금·일 예측)

| 방법 | 연습 test | 일요일 MAE |
|---|---|---|
| E32 그대로 | 27.473 | 30.491 |
| 토요일처럼만 | 27.473 | 30.491 (E32와 같음) |
| 평일처럼만 | 28.019 | 32.441 |
| **반반** | **27.395 (-0.078)** | **30.212 (-0.28)** |

- 섞는 비율 0.5는 **미리 정하고** 한 번만 시험함 (test 보고 비율을 고르지 않음).
- 대회 test 정답은 안 씀. 근거는 노선이 다른 연습 데이터.

## 주의

- 대회 train 검증(4-fold)으로는 확인할 수 없음. 학습에 일요일이 없어서 검증 fold에도 일요일이 없음 → 근거는 연습 모의고사 한 번뿐.
- 반반이 좋아진 이유(추정): 일요일 예측 평균은 오히려 길어졌음(잔차 중앙값 -3.50 → -5.10). 그런데도 MAE가 좋아졌으니, "일요일이 평일과 토요일 중간이라서"보다는 **서로 다른 두 예측을 평균 낸 효과**(모델 섞기와 비슷)로 보임.
- 비교 기준: final_E32 public MAE 25.028 / RMSE 50.106
