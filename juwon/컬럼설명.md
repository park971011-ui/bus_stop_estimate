# 데이터 컬럼 설명

**데이터 한 줄의 의미:** 버스 한 대가 정류장 A에 도착한 순간부터 바로 다음 정류장 B에 도착할 때까지의 기록 하나.

예시 값은 연습 데이터(`data/practice/`)에서 가져옴.

## 1. 식별자

| 컬럼 | 뜻 | 예시 | 참고 |
|---|---|---|---|
| `row_id` | 행 번호 | `PTR000001` | 제출할 때 이 ID로 매칭함. 모델 입력으로 쓰면 안 됨 |
| `vehicle_id` | 차량(버스) 번호 | `DJB130752344` | 연습 데이터에 89대. 운행을 묶을 때 씀 |

## 2. 노선 정보 (같은 노선이면 값이 같음)

| 컬럼 | 뜻 | 예시 | 참고 |
|---|---|---|---|
| `route_id` | 노선 고유 ID | | 연습 4개 노선, 대회 5개 노선 |
| `route_nm` | 노선 번호 | `1`, `102`, `511`, `605` | `route_id`와 1:1 대응 |
| `route_type` | 노선 유형 | 1 급행, 2 간선, 3 지선, 4 외곽, 5 마을, 6 첨단, 7 광역 | 연습 데이터는 1번만 급행, 나머지는 간선 |
| `direction` | 방향 | 0 상행, 1 하행 | |
| `interval_wd` | 평일 배차간격(분) | | |
| `interval_sat` | 토요일 배차간격(분) | | |
| `interval_sun` | 일요일 배차간격(분) | | 노트북에서는 날짜에 맞는 값 하나를 골라 `interval`로 만듦 |
| `first_time` | 첫차 시각 | `545` = 05:45 | HHMM 형식 숫자 |
| `last_time` | 막차 시각 | | HHMM 형식 숫자 |

## 3. 구간 정보 (어느 정류장에서 어느 정류장으로 가는지)

| 컬럼 | 뜻 | 예시 |
|---|---|---|
| `from_stop` | 출발 정류장 ID | |
| `from_name` | 출발 정류장 이름 | `서대전IC` |
| `from_lat` | 출발 정류장 위도 | |
| `from_lon` | 출발 정류장 경도 | |
| `to_stop` | 도착 정류장 ID | |
| `to_name` | 도착 정류장 이름 | |
| `to_lat` | 도착 정류장 위도 | |
| `to_lon` | 도착 정류장 경도 | |
| `stop_seq` | 출발 정류장이 노선에서 몇 번째인지 | 1번 노선 상행 2~21, 하행 22~43 |
| `dist_m` | 두 정류장 사이 거리(m) | `259` |

참고할 점:
- **정류장 이름은 ID와 다를 수 있음.** 이름은 160개, ID는 239개. 길 건너편 정류장처럼 이름은 같아도 ID가 다름. 정류장을 구분할 때는 ID를 씀.
- **`stop_seq`는 하행에서 이어서 번호가 매겨짐.** 하행이 1부터 다시 시작하지 않고 상행 다음 번호부터 시작함.

## 4. 시간 정보

| 컬럼 | 뜻 | 예시 | 참고 |
|---|---|---|---|
| `date` | 출발 정류장에 도착한 날짜 | `2024-09-23` | 문자열이라서 요일·주말 여부는 직접 만들어야 함 |
| `arrive_hour` | 출발 정류장에 도착한 시각의 "시" | 0~23 | 분·초는 없음. 연습 데이터는 5~23시 |

## 5. 정답

| 컬럼 | 뜻 |
|---|---|
| **`tt_sec`** | A 도착부터 B 도착까지 걸린 시간(초). **A에서 정차한 시간도 포함.** 예측해야 하는 값이고, 대회 test에는 없음 |

## 예시 한 줄 읽기

```
vehicle DJB130752344 | 2024-09-23 | 1번 | 상행(0) | 7시 | stop_seq 2 | 서대전IC → (다음 정류장) | 259m | 60초
```

9월 23일 오전 7시대에 1번 버스가 서대전IC에 도착한 뒤, 259m 떨어진 다음 정류장에 도착하기까지 **60초**가 걸렸다는 뜻.

## 모델에 넣을 때 주의할 점

- **`row_id`는 넣으면 안 됨.** 단순한 번호라서 의미가 없음.
- **요일(`dow`)도 바로 넣으면 안 됨.** 학습은 월·화·수·토, 평가는 목·금·일이라 요일이 하나도 겹치지 않음. 대신 주말 여부처럼 묶어서 씀.
- **`from_name`, `to_name`은 문자열이라 그대로는 못 넣음.** 이름 대신 정류장 ID나 구간 단위로 쓰는 게 나음.
- **`vehicle_id`는 그대로 넣기보다 묶는 데 씀.** `date`, `direction`과 같이 쓰면 운행 한 번을 묶을 수 있음. "그날 몇 번째 운행인지" 같은 피처를 만드는 데 유용함.
