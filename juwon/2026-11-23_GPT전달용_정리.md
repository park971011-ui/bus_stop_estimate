# 버스 통행시간 예측 프로젝트 정리 (GPT 전달용, 11/23 기준)

## 1. 과제

- 대전 BIS 데이터로 버스가 정류장 A → 다음 정류장 B까지 걸린 시간 `tt_sec`(초) 예측. 평가 MAE.
- 학습: 월·화·수·토 (154,327행) / 평가 test: 목·금·일 (111,563행, 정답 없음). **학습에 일요일 없음.**
- test 구성: 목 40,515 · 금 40,200 · 일 30,848행 (평일 72.35%)
- 노선 5개: 2(유형 1), 211·311·704(유형 2), B1(유형 7)
- 리더보드: public 30% / private 70%, 하루 3번 제출, 최종 제출은 직접 골라야 함, 노트북 재현성도 평가
- **규칙:**
  - 앙상블 계열 모델만 (XGBoost, LightGBM, CatBoost, RandomForest 등). **MLP 같은 신경망 안 됨.**
  - 외부 데이터 금지
  - "평가 데이터의 정답을 찾거나 추정하려는 시도는 허용하지 않습니다"
- **연습 데이터:** 노선 1·102·511·605, 대회와 같은 구조, test에 정답 있음 → 모의고사로 씀.
  - ⚠️ 연습 test 일요일과 대회 test 일요일이 **같은 날(2024-09-29)**. 연습 일요일 정답으로 무언가를 고르거나 학습하면 규칙 위반 위험. 미리 정한 방법을 **한 번만 확인**하는 용도로만 씀.

## 2. 지금 최고: E46 (public MAE 24.577)

| 단계 | 내용 |
|---|---|
| 피처 35개 | 기본 15 (노선·유형·방향·배차·좌표·순번·거리·시각·주말·출퇴근) + 구간 ID + 첫차·막차 관련 5 + 운행 순서 4 + **회차 힌트 10** |
| 모델 | LightGBM (`regression_l1`, lr 0.02, `num_leaves` 127, `min_child_samples` 10, 1500개, subsample·colsample 0.8, seed 0) × 0.8 + CatBoost (MAE, depth 10, lr 0.08, 2000회, 범주형 노선·구간) × 0.2 = E41 |
| 목·금 | E41 × 0.5 + **평일 전용 LightGBM**(같은 설정, 월·화·수만 학습) × 0.5 |
| 일요일 | "토요일처럼"(주말·토 배차) + "평일처럼"(평일·평일 배차) 예측 섞기. 일요일 배차가 토요일과 같은 노선(211, 311)은 ½씩, 다른 노선(2, 704, B1)은 토요일처럼·평일처럼·그대로(일요일 배차) ⅓씩 |

- **회차 힌트:** 회차 구간(노선마다 상행 구간 중 train 중앙값 최대)은 행 0.67%인데 오차의 6%. 같은 차량의 **다음 운행이 몇 시에 시작하는지** 등 `arrive_hour`에서 만든 피처 10개를 회차 행에만 넣음 (정답 안 씀). 다음 운행이 같은 시 → 중앙값 596초, 다음 시 → 788초.
- 재현: 노트북 `cv_feature_experiments.ipynb` 끝까지 실행 → 18번 섹션이 `submissions/final_E46_wd_route_sunmix.csv`를 만듦 (제출 파일과 완전히 같은 것 확인).

## 4. 검증 방법

- 대회 train 날짜별 4-fold (월·화·수·토 하루씩 빼기). 예상 = 평일 평균 × 0.72 + 토 × 0.28.
- E41 기준: 예상 25.229.
- 평일 전용 실험: 월(화·수로 학습)·화(월·수)·수(월·화). E46 평일 기준 3일 평균 23.261.
- 저장된 검증 예측: `experiments/oof_final_E41.parquet` (lgb, cb, e41), `oof_final_E44.parquet` (wd_lgb).

## 6. 남은 오차 분석 (왜 더 안 줄어드나)

- E46 평일 검증 MAE 23.26.
- **"그날 상황"을 정답으로 알려 줘도 못 이김:** 같은 날·같은 구간·같은 시간대에 지나간 다른 버스들의 실제 중앙값으로 예측하면 25.84 (모델보다 나쁨). 같은 날·같은 시간·같은 구간 버스끼리도 평균 26초씩 다름.
- 오차 50초 넘는 행 13.4%가 전체 오차의 50%. 그중 62%는 실제가 더 느림 (기다린 버스).
- 같은 구간·시간대라도 날마다 크게 다름 (311번 하행 8시: 월 300초, 화 150초, 수 140초). 시간대별 표본 5~9개.
- 결론: 남은 오차는 **버스 한 대마다의 신호 대기·승객 승하차·분 단위 시각** 같은 데이터에 없는 정보. 데이터에 시각은 `arrive_hour`(시 단위)뿐이고, `row_id`는 차량 → 정류장 순서일 뿐 시간 순서 정보 없음.
