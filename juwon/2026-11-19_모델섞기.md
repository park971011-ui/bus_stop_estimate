# 2026-11-19 모델 섞기: LightGBM + CatBoost + XGBoost (E26~E29)

## 한 줄 요약

**같은 피처로 세 종류 모델을 학습해서 섞어 봄. 검증으로 고른 최종 조합은 LightGBM 0.9 + CatBoost 0.1 (XGBoost 0). 연습 test 27.565 → 27.531.**
XGBoost는 섞어도 도움이 안 돼서 빠짐. CatBoost는 **일요일에 특히 강함**.

- 노트북: `bis-travel-time-practice/notebooks/cv_feature_experiments.ipynb` → **"10. CatBoost 섞기"**, **"11. XGBoost까지 섞기"**
- 결과 기록: `bis-travel-time-practice/experiments/results.csv` (E26~E29)
- 검증 예측 저장: `bis-travel-time-practice/experiments/oof_lgb_cb_xgb.parquet` (다시 학습 안 하고 비율만 바꿔 볼 수 있음)
- 제출 파일: `bis-travel-time-practice/submissions/practice_E29_lgb_cb_xgb.csv` (= E27과 같은 예측)

## 1. 모델 섞기란

같은 문제를 **다른 종류의 모델 여러 개**에게 풀게 하고, 답을 **가중 평균**냄.
모델마다 틀리는 방식이 달라서, 섞으면 한 모델의 실수를 다른 모델이 덮어 줄 수 있음.

```
최종 예측 = LightGBM 예측 × a + CatBoost 예측 × b + XGBoost 예측 × c    (a + b + c = 1)
```

세 모델 모두 **나무(트리)를 차례로 쌓는 방식**(부스팅)이지만, 나무를 만드는 규칙이 조금씩 다름.

| 모델 | 특징 |
|---|---|
| LightGBM | 빠름. 가장 잘 나뉘는 곳부터 나무를 키움 |
| CatBoost | 범주형(노선, 구간 ID) 처리에 강함. 나무 모양이 좌우 대칭이라 덜 외움 |
| XGBoost | 가장 오래된 표준 모델. 층마다 고르게 나무를 키움 |

## 2. 무엇으로 돌렸나

| 항목 | 내용 |
|---|---|
| 데이터 | 연습 train 4일 (월·화·수·토) |
| 피처 | **세 모델 모두 E5 그대로** (base + seg + time + trip, 25개) |
| 검증 | 날짜별 4-fold. 각 fold에서 세 모델을 모두 학습하고 검증 예측을 모아 둠 |
| 비율 고르기 | 모아 둔 **검증 예측으로만** 0.1 단위 66가지 조합을 전부 시험 → `예상` 점수가 가장 좋은 조합 |
| 최종 확인 | train 4일 전체로 학습 → 연습 test 채점 (고르는 데는 안 씀) |

### 모델 설정

| 모델 | 설정 |
|---|---|
| LightGBM | E23 설정: `objective='regression_l1'`, `num_leaves=127`, `min_child_samples=20`, `learning_rate=0.03`, 나무 1000개 |
| CatBoost | `loss_function='MAE'`, `depth=8`, `learning_rate=0.08`, 2000회, 노선·구간 ID 범주형 |
| XGBoost | `objective='reg:absoluteerror'`, `max_depth=8`, `learning_rate=0.05`, 나무 1000개, `min_child_weight=20`, 노선·구간 ID 범주형 |

세 모델 모두 채점 기준(MAE)을 직접 줄이도록 학습함. CatBoost·XGBoost는 하이퍼파라미터 조정을 안 함 (기본에 가까운 설정).

## 4. 알게 된 것

- **섞으면 조금 좋아짐.** 최종 조합이 LightGBM 혼자보다 test -0.034초. 검증과 test가 같은 방향.
- **XGBoost는 도움이 안 됨.** 혼자서도 가장 약하고(test 27.819), 특히 일요일(31.30)이 나쁨. 검증에서도 섞는 비율 0이 뽑힘.
- **CatBoost는 일요일에 강함.** 일요일 30.73 → **29.82 (-0.91초)**. 지금까지 일요일을 가장 크게 줄인 방법. 대신 평일은 0.5초 약함.
- **그런데 토요일 검증에선 CatBoost가 약함** (36.99 vs LightGBM 36.23). 그래서 검증으로 고르면 CatBoost를 10%만 섞게 됨.
  → **토요일과 일요일이 다르게 움직인다**는 걸 또 확인 (E11 첨두 수정, E20, E25 차량 피처에 이어 네 번째).
- test에서는 참고용 "반반"(27.502)이나 "1/3씩"(27.522)이 더 좋았음. 하지만 **test를 보고 비율을 고르면 test에 맞추는 것**이라 쓰지 않음 (대회에선 test 정답이 없음).

## 6. 대회 데이터에서 할 것

- 대회 train에 **일요일이 있으면** 그 날을 검증 fold로 넣어서 비율을 다시 고름 → CatBoost 비중이 커질 수 있음.
- CatBoost는 아직 하이퍼파라미터 조정을 안 함. 조정하면 혼자 점수가 더 좋아져서 섞는 효과도 커질 수 있음.
- 노트북 10·11번 셀을 그대로 돌리면 비율까지 자동으로 다시 고름 (`PHASE = 'final'`로만 바꾸면 됨).

## 7. 추가: 최고 조합 하이퍼파라미터 추가 조정 (E30~E32)

**한 일:** 최고 조합(E27)의 두 모델을 각각 더 조정한 뒤, 섞는 비율을 다시 고름.
노트북: `cv_feature_experiments.ipynb` → **"12. 최고 조합 하이퍼파라미터 추가 조정"**
방식: 하나씩 차례로 비교, **0.02초 넘게** 좋아질 때만 바꿈 (seed만 바꿔도 표준편차 0.01초 흔들리므로, 그 2배).

### LightGBM 추가 조정 (E30, E23 설정 28.774에서 시작)

| 단계 | 시험한 값 | 예상 | 직전 대비 | 결과 |
|---|---|---|---|---|
| `min_child_samples` | 20 → **10** | 28.724 | **-0.051** | **채택** |
| `learning_rate` + 나무 수 | 0.03 + 1000 → **0.02 + 1500** | 28.702 | **-0.021** | **채택** |
| `subsample` | 0.7 | 28.728 | +0.026 | |
| | 0.9 | 28.690 | -0.012 | **0.8 유지** (기준 미달) |

→ E23 조정 때와 같은 방향(더 세세하게, 더 천천히)으로 계속 좋아짐.

### CatBoost 조정 (E31, E26 설정 29.357에서 시작)

| 단계 | 시험한 값 | 예상 | 직전 대비 | 결과 |
|---|---|---|---|---|
| `depth` (나무 깊이) | 6 | 29.686 | +0.329 | |
| | **10** | **28.982** | **-0.375** | **채택** (가장 큰 개선) |
| `learning_rate` + 반복 수 | 0.05 + 3000 | 29.025 | +0.043 | |

→ CatBoost는 나무를 더 깊게(8 → 10) 만드는 것만으로 크게 좋아짐. 기본 설정이 이 데이터엔 너무 단순했음.

### 알게 된 것

- **새 최고: test 27.473** (E27보다 -0.058, 교수님 베이스라인보다 **-0.58**). 검증과 test가 같은 방향으로 좋아짐.
- **LightGBM은 조정할 때마다 꾸준히 좋아짐** (E5 27.655 → E23 27.565 → E30 27.501).
- **CatBoost는 검증은 크게 좋아졌는데(29.357 → 28.982) test는 그대로**(27.674 → 27.677). 깊이 10이 평일(목 26.12 → 25.87)은 좋게, 일요일(29.82 → 30.42)은 나쁘게 만듦. 깊은 나무가 평일·토요일 패턴을 더 세세하게 배운 대신 일요일 강점이 줄어든 것으로 보임.
- 학습 시간은 늘어남: LightGBM 나무 1500개, CatBoost 깊이 10이라 4-fold 한 번에 약 4분.
